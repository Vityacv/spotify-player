# Data Export / Import

## Overview

spotify-player now ships Python helpers to snapshot and restore Spotify library data using the cached OAuth refresh token (`~/.cache/spotify-player/oauth_token.json`). The scripts talk directly to the Spotify Web API, so they aren’t tied to librespot’s Connect session.

## Authentication prerequisite

- Run once: `scripts/launch_player authenticate`
  - Complete the browser flow.
  - After that an `oauth_token.json` file lives under `~/.cache/spotify-player/`; the scripts refresh tokens automatically on each run.

## Export scripts

- `python scripts/export_library.py --output ./library_exports`
  - Dumps JSON files for:
    - Playlists (under `library_exports/playlists/`)
    - Liked tracks (`saved_tracks.json`)
    - Saved albums (`saved_albums.json`)
    - Followed artists (`followed_artists.json`)
    - Saved shows (`saved_shows.json`)
    - Saved episodes (`saved_episodes.json`)
  - Add `--skip-playlists` to export only non-playlist data.

- `python scripts/export_playlists.py --output ./playlist_exports`
  - Narrower export that only dumps playlists.

Each export writes an `index.json` summarizing counts and user info.

## Import scripts

- `python scripts/import_library.py --input ./library_exports --prefix "Restored - "`
  - Restores saved tracks/albums/artists/shows/episodes.
  - Recreates playlists unless `--skip-playlists` is supplied. The prefix is optional but helps distinguish copies.

- `python scripts/import_playlists.py --input ./playlist_exports`
  - Only recreates playlists stored in that directory.

During import the scripts chunk requests (50–100 ids per call) to obey API limits. They de-duplicate IDs automatically and only add content (no removal of items missing from the snapshot).

## Notes

- All scripts require a valid refresh token in `~/.cache/spotify-player/oauth_token.json` (generated by the authenticate flow).
- If you want to test against another account, copy the exported directory and run the import scripts after authenticating that account.
- There is no “wipe then restore” mode; imports are additive.
